# CPack

## Project Description

CPack is a command-line compression and archiving tool developed entirely in C.
The project aims to reduce file size using lossless Huffman coding and store
the compressed data in a custom binary `.cpk` format.

The tool will allow users to compress files, decompress them back to their
original form, and view basic information about the generated archive.

## Overview

The project will explore how data can be represented more efficiently while
preserving the original information. It will involve Huffman coding, data
structures such as priority queues and binary trees, file handling, bit-level
data manipulation, and custom binary file formats.

The project will be developed incrementally, starting with the core compression
and decompression functionality and adding additional features as the project
progresses.
